Warwick Summer School Portal

A Flask-based web application designed to streamline course discovery, student applications, and administrative workflow management for the University of Warwick Summer School.

Flask SQLite Bootstrap Jinja2 Python

Project Overview

This project was developed to improve how prospective students browse and apply for Warwick Summer School courses while providing administrators with tools to manage and review submissions efficiently.

The platform includes a course discovery interface, application submission workflow, administrator dashboard, and database-driven application management system.

My Role

  • Full-stack web development
  • Database design and management
  • Frontend UI implementation
  • Flask route development
  • Session authentication
  • Application workflow design

Key Features

CRUD Functionality

Implemented create, read, update, and delete operations for managing student applications.

Session Authentication

Protected administrator routes using Flask session-based authentication.

Responsive UI

Built responsive pages using Bootstrap and reusable Jinja templates.

Database Management

SQLite was used to store applications, timestamps, and status updates.

Technical Architecture

The application uses Flask routes to manage application workflows while SQLite handles persistent data storage.

Challenges & Solutions

One challenge involved managing administrator access securely while maintaining a simple user workflow. Session-based authentication was implemented to protect restricted administrative routes.

Another challenge involved handling large numbers of applications efficiently. Future improvements could include asynchronous processing and automated email notifications.
