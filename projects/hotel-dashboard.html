Hotel Operations Analytics Dashboard

Built a Tableau dashboard and analytics strategy for Stellar Hotel Group, a six-property hotel chain.

The Problem

The company relied on disconnected systems for property management, CRM, marketing, and reporting, resulting in fragmented data and inefficient decision-making.

My Role

  • Business analysis
  • Dashboard design
  • Data visualization
  • Technology recommendations

Dashboard Features

  • Occupancy trends
  • Revenue KPIs
  • Customer satisfaction metrics
  • Cross-property comparison

Key Insights

  • Manual reporting slowed operational decisions
  • Data silos prevented unified reporting
  • Seasonal occupancy patterns affected revenue

Recommended Architecture

Proposed centralized cloud storage, ETL pipelines, API integrations, and real-time reporting dashboards.
